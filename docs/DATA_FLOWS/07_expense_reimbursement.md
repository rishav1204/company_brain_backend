# Golden Path 07 — Expense Reimbursement

```text
Employee claim (M16) → Receipt attach → Workflow approval (M2) → Payment (M22)
```

## Steps

1. Expense claim created with line items and policy checks (M34).
2. Manager approval via M2.
3. Approved claim → payment batch (human execution).
